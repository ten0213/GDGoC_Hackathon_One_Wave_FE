# Connectable

> AI가 채점하는 프론트엔드 코딩 과제 플랫폼

---

## 소개

**Connectable**은 기업과 지원자를 연결하는 AI 기반 프론트엔드 구현과제 자동 채점 플랫폼입니다.

기업의 채용 과정에서 프론트엔드 코딩 과제를 출제하고 평가하는 데는 많은 시간과 인력이 소요됩니다. Connectable은 이 과정을 자동화하여, 기업은 과제를 출제하고 지원자는 솔루션을 제출하면 **AI(Playwright 기반 E2E 테스트)가 자동으로 채점**하여 객관적인 결과를 제공합니다.

---

## 핵심 기능

### 기업을 위한 기능
- 프론트엔드 구현 과제 생성 및 세부 채점 항목 설정 (최대 3개)
- 지원자별 제출 현황 및 채점 결과 한눈에 확인

### 지원자를 위한 기능
- 과제 목록 조회 및 상세 내용 확인
- 구현한 프로젝트의 배포 URL 제출
- AI 채점 결과 실시간 확인 (항목별 Pass/Fail 및 통과율)

---

## 어떻게 동작하나요?

```
1. 업로드       →  기업이 과제를 생성하고 채점 기준을 설정합니다.
2. 제출         →  지원자가 구현한 프로젝트 URL을 제출합니다.
3. AI 채점      →  Playwright 기반 E2E 테스트가 자동으로 실행됩니다.
4. 결과 리포트   →  항목별 Pass/Fail 및 통과율 리포트가 제공됩니다.
```
